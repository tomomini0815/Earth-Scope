# World Explorer Quests

下記プロンプトを参考に世界地図学習アプリを作成してください。

世界地図学習アプリ 要件定義書

1. アプリ概要

項目 内容 アプリ名(仮) ワールドナビ / GeoQuest など ターゲット 中学生・高校生(受験生含む) コンセプト インタラクティブな世界地図をベースに、各国の歴史・文化・人口・軍事力・経済・地理的特色などを楽しく学べる学習アプリ プラットフォーム Webアプリ(レスポンシブ対応、PC/タブレット/スマホ) コア体験 地図上の国をクリック→情報パネル表示→クイズで定着確認→学習進捗が可視化される

2. ターゲットユーザーと利用シーン

中学・高校の社会科(地理・歴史・公民)の授業や自主学習

高校入試・大学入試(共通テスト・地理総合・歴史総合など)の対策

「なんとなく世界の国のことを知りたい」というカジュアルな興味

利用シーン例:

通学中にスマホで1国分だけ復習

定期テスト前にクイズモードで演習

自由研究やレポート作成のための情報収集

3. コア機能要件

3.1 インタラクティブ世界地図

SVGまたはGeoJSONベースの世界地図を表示

国ごとにクリック/タップ可能(ホバーで国名ポップアップ)

ズーム・パン操作対応

大陸別・地域別のフィルタ表示(アジア、ヨーロッパ、アフリカなど)

学習済み国・未学習国を色分け表示(進捗の可視化)

3.2 国別情報コンテンツ(受験対応)

各国ページに以下のカテゴリをタブ形式または カード形式で表示:

基本情報:首都、国旗、公用語、面積、時差

歴史:建国の経緯、主要な歴史的出来事の年表、他国との関係史

文化:宗教、伝統、食文化、世界遺産、有名な人物

人口・社会:人口数、人口増減率、人口ピラミッド、都市化率、平均年齢

経済:GDP、主要産業、貿易relations、資源

軍事・国際関係:軍事力指数、同盟関係(NATOなど)、国際機関への加盟状況

地理的特色:気候、地形、自然災害リスク、隣国との国境問題

受験ポイント:入試に出やすいキーワードを「一問一答」形式でまとめた欄

※ 軍事力情報は客観的な公開データ(兵力数、軍事費など)に限定し、対立を煽らない中立的な表現にする。

3.3 学習・ゲーミフィケーション機能

クイズモード:国名当てクイズ、国旗クイズ、歴史年表の並べ替えクイズなど

バッジ/称号システム:大陸を制覇するとバッジ獲得

学習ストリーク:連続学習日数の記録

ランキング(任意):クラス内や全国のスコア比較(ソーシャル要素、任意でオフ可能)

フラッシュカード:重要語句の暗記モード

3.4 検索・比較機能

国名・キーワードでの検索(あいまい検索対応)

2〜3か国を選んで人口・GDP・軍事費などを比較するグラフ表示

「似ている国」レコメンド(気候や経済規模が近い国など)

3.5 進捗管理・マイページ

学習した国、クイズの正答率、苦手分野の可視化

保護者・教師向けの学習レポート出力(任意機能)

3.6 その他

音声読み上げ機能(国名・用語の発音)

多言語対応は不要(日本語のみでよい、必要なら英語切替)

オフライン閲覧(PWA化、任意)

4. デザイン要件(UI/UX)

4.1 デザインの方向性

キーワード:楽しい・カラフルだが情報が整理されている・「学習アプリ」らしい信頼感

地図はゲーム的な質感(フラットデザイン+柔らかい配色)にしつつ、情報パネルは教科書的に読みやすいレイアウトにする

対象が中高生のため、子供っぽすぎず、かつ堅すぎない「ちょうどいい」トーン

4.2 画面構成(主要画面)

トップ画面(世界地図)

中央に世界地図、上部に検索バー、右上にマイページ・進捗アイコン

大陸フィルタをタブで上部に配置

国別詳細画面

上部:国旗・国名・基本データのヒーローエリア

中部:カテゴリタブ(歴史/文化/人口/軍事/経済/地理/受験ポイント)

下部:関連クイズへのCTAボタン

クイズ画面

1問1画面、進捗バー表示、正解時のアニメーション演出

マイページ

学習済みマップ(色分け)、バッジ一覧、正答率グラフ

4.3 配色・タイポグラフィ方針

ベースカラー:淡いブルー〜グリーン系(地図・海のイメージ、学習系アプリの信頼感)

アクセントカラー:オレンジ or イエロー(クイズ正解・バッジなど達成感を出す部分)

フォント:見出しはやや丸みのあるゴシック、本文は可読性重視の標準ゴシック

大陸ごとにテーマカラーを分ける(アジア=赤系、ヨーロッパ=青系など)と視認性が上がる

4.4 モバイル・アクセシビリティ

スマホでは地図はピンチズーム対応、国タップ時はボトムシートで情報表示

文字サイズ変更機能、コントラスト比のWCAG AA準拠

色弱対応(進捗の色分けにパターンやアイコンも併用)

5. データ・技術要件

地図データ:Natural Earth / GeoJSON形式の世界地図データを利用

国データ:人口・GDP・軍事費などは信頼できる公開データ(World Bank, CIA World Factbook, SIPRIなど)を基に定期更新できる構造にする

データ更新性:国データはJSON/DBで管理し、後から編集・追加しやすい設計にする

技術スタック(推奨):React + TypeScript、地図はreact-simple-maps or Leaflet、グラフはRecharts、状態管理はZustand/Redux、バックエンドは任意(Firebase等でも可)

レスポンシブ:PC/タブレット/スマホの3ブレークポイント対応

6. AIコーダー向けプロンプト(そのままコピペ用)

以下をAIコーディングツール(Claude Code等)にそのまま渡してください。

あなたはフロントエンド開発が得意なシニアエンジニアです。以下の要件で、中高生向けの
「世界地図から各国のことを学べる学習アプリ」のWebアプリを実装してください。

【アプリ概要】
- インタラクティブな世界地図を表示し、国をクリックすると、その国の歴史・文化・人口・
  軍事力・経済・地理的特色・受験に出やすいポイントなどをまとめた情報パネルが開く。
- 学習の定着のためにクイズモード、進捗管理、バッジ機能を持つ。

【必須機能】
1. 世界地図(SVGまたはGeoJSONベース)。国ごとにクリック/ホバー可能。大陸別フィルタ。
   学習済み/未学習を色分け表示。
2. 国別詳細ページ:基本情報・歴史・文化・人口社会・経済・軍事国際関係・地理的特色・
   受験ポイントのタブ切り替えUI。
3. クイズモード:国名当て、国旗当て、年表並べ替えなど複数形式。正誤判定とスコア表示。
4. 比較機能:2〜3か国を選んで人口・GDP・軍事費等をグラフで比較。
5. マイページ:学習済み国の地図表示、正答率、バッジ一覧。
6. 検索バー(国名のあいまい検索)。

【デザイン要件】
- ベースカラーは淡いブルー〜グリーン系、アクセントはオレンジ/イエロー。
- 地図はゲーム的で親しみやすい質感、情報パネルは教科書的に読みやすいレイアウト。
- 大陸ごとにテーマカラーを分ける。
- レスポンシブ対応(PC/タブレット/スマホ)。スマホでは国タップ時にボトムシートで
  情報表示。
- 中高生向けなので子供っぽすぎず堅すぎないトーン。

【技術要件】
- React + TypeScript を使用。
- 地図表示には react-simple-maps または Leaflet を使用し、GeoJSON形式のデータを
  読み込めるようにする。
- グラフ表示には Recharts を使用。
- 国データ(人口・GDP・軍事費・歴史年表・文化情報など)はJSONファイルで管理し、
  後から追加・編集しやすい構造にする。まずは主要国(20か国程度)分のサンプルデータ
  を作成する。
- 状態管理はReactのContext APIまたはZustandを使用。
- コードはコンポーネント単位で分割し、可読性・保守性を重視する。

【データの注意点】
- 軍事力に関する情報は、客観的な公開統計(兵力数・軍事費など)のみを扱い、
  特定国への偏った評価や対立を煽る表現は避ける。
- データの出典を明記できる構造にする(例:各データ項目に source フィールドを持たせる)。

【進め方】
1. まずプロジェクトの構成(フォルダ構成・主要コンポーネント一覧)を提示してください。
2. その後、世界地図表示 → 国別詳細パネル → クイズ機能 → 比較機能 → マイページ、
   の順に実装を進めてください。
3. 各ステップの後に動作確認方法を教えてください。
